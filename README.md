# Data Structures & Algorithms

Implementacje struktur danych i algorytmów w C++ 
realizowane w ramach przedmiotu Algorytmy 2 (ZUT Szczecin).

## Zawartość
- **BST** – Binary Search Tree
- **RBT** – Red-Black Tree
- **Heap** – kopiec binarny
- **Hash Table** – tablica mieszająca
- **Linked List** – lista jednokierunkowa
- **Kruskal** – algorytm minimalnego drzewa rozpinającego
- **Sort** – algorytmy sortowania
- **Dyn-arr** – dynamiczna tablica
